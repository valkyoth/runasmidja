admission checks prevented unauthorized images, but competing builds could
invalidate local receipt/archive publication. A global exclusive lock now spans
all build mutations; shared locks protect coherent reads and the full archive
scan. Automatic builds recheck completed receipts after waiting. The per-stack
lock is still separate. Lock/state custody and release on failure/death are
explicit, and the persistent lock is never deleted.

exercise competing direct/automatic builders, concurrent readers, interrupted

locking and publication are exercised. Invalid custody subcases cover symlink,
mode, ownership, nonregular and hard-linked lock files. Existing failure/retry
regressions run through the new real lock as well.
