# v0.1.0 — Repository foundation

Status: unpublished; local verification PASS; maintainer-accepted pentest PASS.
GitHub checks, version tagging and distribution publication are pending.

Goal: provide the small Rust workspace, security/testing foundation and bounded
implementation plan needed to build Runasmidja in subsequent releases.

## Delivered

- Six workspace packages at 0.1.0, Rust 1.99.0/edition 2024/resolver 3 and EUPL-1.2.
  Five portable facade/boundary crates are always no_std/no alloc and forbid
  first-party unsafe; no external runtime dependencies or sibling paths.
- A Linux development health probe, exercised directly and as a static musl,
  scratch/non-root/read-only container. It serves health only, not product routes.
- Automated rootless Podman fixtures for PostgreSQL 19beta4, TLS OpenBao 2.7.1
  and ACL Valkey 9.1.2, with actual authentication/permission/restart tests.
- Adapted repository/GitHub policy, pinned tool/actions/images, dependency audit,
  weekly freshness, documentation/link/code-size guards and negative fixtures.
- Architecture, security, secret/search contracts and 386 bounded pre-1.0 passes,
  preserving all 240 supplied workstreams. 1.0.0 remains the first production
  website/API release; desktop/mobile GUI and conditional Aesynx work follow.
- Pentest remediation: explicit browser origin/offline/remote trust profiles and
  future header owners; optimization-safe smoke validation; live-child ephemeral
  probing with bounded/flushed readiness and cleanup; adversarial regressions.

The optimized Python suite and actual normal/optimized native and optimized
container probes pass. Dependency/license/advisory audits, fresh upstream
metadata, service smoke/restart, reference integrity and SBOM inventory checks
pass. The CycloneDX SBOM covers all six workspace packages.

resolved for this foundation scope, no new actionable security issue found.
The [assessment report](../security/pentest/v0.1.0.md) binds that retest and the
final documentation/metadata review to the finalized source. Browser remediation

Versions reviewed: cargo-deny 0.20.2, cargo-audit 0.22.2, cargo-sbom 0.10.0 and
checkout v7.0.1. OpenBao SDK 2.2.2 and Meilisearch v1.54.3 are monitored only;
neither is admitted to the runtime graph or starts as a product dependency.
SDK 2.2.2 registry metadata was reviewed after detecting 2.2.1 monitor drift.

## Scope and residual limits

There are no transformations, browser workbench, public API or production
service claims. The serial development probe has no whole-connection deadline.
Current fixture passwords are generated locally before OpenBao and retain
private plaintext copies; OpenBao-first origin/delivery work belongs to 0.2.0
and later passes. Workflow/graph enforcement, fixture ownership/drift, actual
cache expiration and trusted distribution evidence still have explicit owners.
PostgreSQL beta and local custody/transport shortcuts are development-only.
