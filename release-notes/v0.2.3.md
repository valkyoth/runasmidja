# Runasmidja 0.2.3 — Wolfi OpenBao fixture

Status: implementation candidate; maintainer pentest RETEST REQUIRED. No tag or push.
Baseline: signed v0.2.2. All six crates are 0.2.3 and publish=false.

## Pentest remediation

SAST-001 (Low) identified a race between builders sharing the OpenBao artifact
cache. Global exclusive writer/shared reader locking now protects coherent
publication and scanning, with concurrent cold-start rechecks and real
multiprocessing regressions. Maintainer retest is required; see the
[assessment](../security/pentest/v0.2.3.md).

The follow-up review confirms that fix and identifies SAST-002 (Low): concurrent
SBOM publication could collide or retain another scan's evidence. Each service
now serializes the full scan/publication transaction and retains image/content-
keyed immutable snapshots. Probe inventory is annotated before publication;
identity-checked export uses the explicit snapshot. OpenBao validation no longer
returns an unlocked archive path. Maintainer retest remains required.

## Changes

Package the exact signed upstream OpenBao 2.7.1 static executable on signed
Wolfi, retaining upstream license and exact image/Go/OS inventory. Admission
binds source/base signatures, executable hash/ABI, exported image/archive and
local recipe receipt. Operational scanner errors and blocking findings prevent
publication. The existing UNKNOWN advisory remains visible with separate,
expiring not-affected evidence bound to the new exact image.

The isolated v023-wolfi-bao fixture supports explicit same-version switches
between the admitted official and Wolfi images without resetting vault data,
credentials or recovery/TLS custody. Private checkpoints bind interrupted retries.
Real qualification covers fresh and retained startup, seal/identity/CA denials,
root revocation, service permissions, audit exhaustion/recovery and resource
limits. Negative tests exercise material, ownership, archive/recipe, scanner,
publication and retry failures, including optimized Python.

## Compatibility and limits

No product Rust API, external Rust dependency, SDK, website or browser feature
is added. Portable crates stay no_std and unsafe-forbidden. Heavy image/service
checks remain local; GitHub CI and CodeQL Default are unchanged. Earlier fixture
data is retained; see the [operating guide](../docs/local-stack.md).

Trusted local assembly is not a signed distributed release or reproducible-source
build. Base shell/libraries remain inventoried. Go module inventory is not complete
third-party redistribution-license qualification; no image distribution is added.
Only built-in KV/AppRole and
PebbleDB are qualified; external plugins are not. Audit retention remains finite,
OpenBao root filesystem remains writable, PostgreSQL is beta, and development
credential delivery/recovery/TLS limitations remain. The OpenBao advisory review
expires 2026-11-02. No security certification or production readiness is claimed.
