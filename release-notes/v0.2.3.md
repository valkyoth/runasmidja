# Runasmidja 0.2.3 — Wolfi OpenBao fixture

Status: maintainer pentest PASS; GitHub and tag pending. Nothing pushed or tagged.
Baseline: signed v0.2.2. All six crates are 0.2.3 and publish=false.

The designated maintainer accepted `11f92bc` on 2026-10-04 with no new findings.
SAST-001 through SAST-017 are remediated and retested. This is a compatible
Linux/amd64 development-fixture patch, not production website readiness.

## Changes

Package the exact signed upstream OpenBao 2.7.1 static executable on signed Wolfi,
retaining its MPL-2.0 license and exact image/Go/OS inventory. Admission binds input
signatures, executable hash/static ABI, archive/config/layers and recipe receipt.
The isolated fixture preserves vault custody, data and scoped credentials during
same-version official/Wolfi switches. Tests cover audit exhaustion/recovery,
auth/ACL/SQL, outages/restarts, ownership/disclosure checks and resource limits.

Global artifact locks protect builds and archive readers; per-service locks
protect scans, immutable snapshots and exports. Public exports bind service,
image and content to canonical destinations. Inventory checks enforce descriptor
custody, bounded reads/traversal, minimum CycloneDX structure, historical service
bindings, strict JSON/Unicode and known private-path detection. Regression tests
cover concurrency, failed publication/retry, parser differentials, resource limits
and path/URI normalization. The strict relative-module allowance preserves real
Go inventories. Privacy checks remain known-pattern detection, not proof that
arbitrary strings are nonsensitive or universal URI decoding.

## Verification and publishing

223 Python tests pass normally and optimized, with Rust debug/release/all-features,
formatting, Clippy, rustdoc and no_std targets. Dependency/license audit, live
freshness, native/scratch probe and retained-service/fault qualification pass.
Unchanged prior build, cold-vault, switch and Wolfi-probe evidence is retained;
see the [release check](../docs/releases/v0.2.3-release-check.md).

No Rust API, Cargo dependency, browser or production-server behavior is added.
All six crates remain publish=false. Release automation checks source/report
metadata only; it cannot push commits/tags, upload images or publish any crate.
Heavy qualification stays local. GitHub CI remains code/dependency-only with
CodeQL Default. Push and version-tag actions remain separate maintainer steps.

## Compatibility and limits

The assembled image trusts local custody; it is not publisher-signed or proven
bit-for-bit reproducible. Go module inventory is not complete redistribution-
license qualification; no image distribution is added. Built-in KV/AppRole/
PebbleDB are qualified; external plugins are not. Audit retention is finite,
OpenBao's root filesystem remains writable, PostgreSQL is beta, and documented
fixture recovery/credential/TLS limitations remain. The retained OpenBao UNKNOWN
not-affected review expires 2026-11-02. No security certification is claimed.
