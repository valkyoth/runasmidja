The fixture initializes TLS OpenBao before PostgreSQL or Valkey. OpenBao issues
three passwords, persists version-1 KV records with create-only writes and
provides separate scoped provisioning/runtime reads. Startup verifies both
identities before consumers run. Root revocation is confirmed; recovery custody
stays outside service mounts. Interrupted setup and restart retain credentials
and PostgreSQL data. Vault/TLS/identity failures have no local-secret fallback.

PostgreSQL 19beta4 is built from pinned official source on a verified Wolfi base.
Public builds use checked CPU/memory/PID limits, private bounded storage and
streamed 512 MiB archive limits. Candidates are scanned, imported and checked
before publishing the final receipt. Scan/import failures preserve prior
committed artifacts; interrupted publication permits automatic rebuild.
The default profile is v02-admission-ready; previous fixture data stays intact.

Image admission requires reviewed provenance and exact-image inventories.
Every nonzero scanner exit rejects before report processing. Completed reports
reject untriaged UNKNOWN/HIGH/CRITICAL findings. OpenBao's retained UNKNOWN has
an exact-image, evidence-bound not-affected review expiring 2026-11-02.
Valkey retains its approved exact-digest provenance exception. The original
PostgreSQL image's 42 HIGH/CRITICAL findings remain blocked, without a CVE waiver.

All submitted findings are resolved for this scope: verified-archive tool
installation, bounded process/log/audit/build resources, durable local custody,
image admission, SBOM path privacy, safe process cleanup, scanner completion and
retryable receipt publication. The maintainer found zero new findings on retest.
The [assessment](../security/pentest/v0.2.0.md) and
[remediation history](../security/pentest/v0.2.0-remediation.md) retain the evidence.

Verification covers 111 normal/optimized Python regressions, all Rust profiles,
Clippy/fmt/rustdoc/no_std targets, actual native/container probes, service fault/
restart/persistence/authorization/disclosure checks, and 12 PostgreSQL startup
denials. Dependency audits, live freshness and committed whitespace pass.
Readme/manifests/lockfile use version 0.2.0; the reviewed compiler is Rust 1.99.0.
Release readiness is metadata-only and cannot push or publish any crate;
all six manifests have publish=false.

than claiming bit-for-bit reproducibility or portable publisher signing. Audit
retention is finite; persistent private delivery, full fixture drift checks,
